# Moto Circolare Uniforme (MCU)

- Velocità angolare: $\omega = \dfrac{\Delta\theta}{\Delta t}$ [rad/s]
- Periodo: $T = \dfrac{2\pi}{\omega}$ [s]
- Frequenza: $f = \dfrac{1}{T}$ [Hz], $\omega = 2\pi f$
- Velocità tangenziale: $v = \omega r$
- Legge oraria angolare: $\theta(t) = \theta_0 + \omega t$

**Accelerazione centripeta:**
$$a_c = \frac{v^2}{r} = \omega^2 r$$
