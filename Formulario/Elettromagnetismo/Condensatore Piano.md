# Condensatore Piano

**Capacità e carica accumulata:**
$$C = \epsilon_0\frac{A}{d} \qquad Q = CV$$

Dove:
- $C$ = capacità (Farad)
- $A$ = area di ciascuna armatura (m²)
- $d$ = distanza tra le armature (metro)
- $Q$ = carica accumulata sulle armature (Coulomb)
- $V$ = differenza di potenziale tra le armature (Volt)
- Se il condensatore è isolato (scollegato dalla batteria) $Q$ resta costante: variando $d$ (e quindi $C$), è $V=Q/C$ a cambiare
