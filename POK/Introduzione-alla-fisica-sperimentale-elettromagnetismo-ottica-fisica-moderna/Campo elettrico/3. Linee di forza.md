# Linee di Forza

## 5 Regole Fondamentali

| Regola | Descrizione                                                          |
| ------ | -------------------------------------------------------------------- |
| 1      | Il campo **E** è **tangente** alle linee di forza                    |
| 2      | Le linee di forza **non si possono intersecare** tra loro            |
| 3      | Le linee di forza **nascono sempre da cariche positive**             |
| 4      | Le linee di forza sono sempre **entranti dentro cariche negative**   |
| 5      | Il campo **E** è **proporzionale alla densità** delle linee di forza |

## Esempio: Dipolo Asimmetrico

**Configurazione:**
- Carica positiva: $+q$
- Carica negativa: $-2q$
